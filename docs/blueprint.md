# **App Name**: The Crystal Coupe

## Core Features:

- Palate Trajectory Tracking: Tracks the user's flavor and texture preferences based on their responses.
- Polarizing Element Filtering: Filters out drinks containing elements the user dislikes (e.g., smoke, excessive bitterness).
- Drink Recommendation Algorithm: Recommends drinks based on a custom scoring algorithm that matches user preferences.
- Drink Discovery Chatbot: Allow the users to upload the description of ingredients they have and it will search from a cocktails API to get recipes that use those ingredients as a tool.

## Style Guidelines:

- Primary color: '#B7410E' (Rust) evokes the warmth and richness of classic cocktails.
- Background color: '#FDFBF7' (Cream) provides a clean, vintage feel.
- Accent color: '#556B2F' (Olive) complements the rust, for a refined and balanced aesthetic.
- Headline font: 'Playfair', a modern sans-serif with a high-end feel. Body font: 'PT Sans' for readability.
- Simple, geometric icons, influenced by mid-century design.
- CSS Grid for the palate matrix, ensuring a structured and visually appealing presentation.
- Subtle transitions for a smooth user experience.
